# Lab 2: Initializing a Repository and Publishing Your First Commits

## Scenario

You are starting a new project at `~/workspace/my-project`. You need to initialize a Git repository, record two initial documentation commits (`README.md` and `notes.md`) with clear commit messages, recover `README.md` after an accidental working-tree modification, and publish your `main` branch to the remote repository (`http://git-server:3000/student/my-project.git`).

## Objectives

1. Initialize a Git repository at `~/workspace/my-project`.
2. Create, stage, and commit `README.md` and `notes.md` as separate commits with descriptive messages.
3. Restore `README.md` to its committed state after an unwanted working-tree modification.
4. Configure `origin` and push `main` with upstream tracking enabled.
