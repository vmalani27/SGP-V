How It Works

Get up and running in 3 intuitive steps.

STEP 1 Install

labops setup

One command verifies your hardware virtualization and installs all required sandboxing components.

$ labops setup
[✓] Base images configured
STEP 2 Launch

labops start

Boots your local secure runtime and opens the interactive lab dashboard in your browser.

$ labops start
Opening http://localhost:3000
STEP 3 Practice

Open Terminal

Complete hands-on tasks in real-time, get instant pass/fail validation, and progress through tracks.

student@lab:~$ docker ps
Task 1 Verified [PASS]

System Requirements & Prerequisites

Make sure your workstation meets the baseline specs before getting started.

OPERATING SYSTEM

macOS 12+, Windows 10/11, or Linux

Hardware virtualization (VT-x / AMD-V) must be enabled in your system BIOS/UEFI.

SYSTEM MEMORY

4 GB RAM (8 GB Recommended)

LabOps reserves a 3 GB sandbox slice, leaving the rest free for your browser and editor.

STORAGE SPACE

15 GB Free Disk Space

Needed to download Ubuntu base images and store pre-pulled container layers.

⚠️

Required Prerequisites on Your Machine

Because LabOps runs hardware-level isolated sandboxes without host Docker, you must have the hypervisor and driver installed:

1. Hypervisor Backend Required

Install Oracle VirtualBox (7.0+) or VMware Workstation / Player / Fusion.

winget install Oracle.VirtualBox
2. HashiCorp Vagrant Required

Used by the LabOps CLI to coordinate and spin up the sandbox runtime automatically.

winget install HashiCorp.Vagrant

💡 Tip: Running labops doctor will automatically scan for these dependencies and print the exact one-click install commands for your platform if missing.
